# Handwritten Character Recognition

## Project Overview

This project uses Machine Learning to recognize handwritten digits from images. The model is trained on a handwritten digit dataset and predicts the correct digit based on image patterns.

## Technologies Used

* Python
* NumPy
* Matplotlib
* Scikit-learn

## Workflow

1. Load the handwritten digit dataset.
2. Visualize the digit images.
3. Split the dataset into training and testing sets.
4. Train a Random Forest Classifier.
5. Evaluate model accuracy.
6. Predict handwritten digits from images.

## Result

The model successfully recognizes handwritten digits with high accuracy and demonstrates the basics of image classification using machine learning.
