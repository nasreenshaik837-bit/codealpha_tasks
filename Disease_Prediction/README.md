# Disease Prediction from Medical Data

## Project Overview

This project predicts the possibility of heart disease using machine learning techniques. The model is trained on medical data such as age, blood pressure, cholesterol level, and other health indicators.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Workflow

1. Load and analyze the dataset.
2. Preprocess the data.
3. Split data into training and testing sets.
4. Train a machine learning model.
5. Evaluate model performance.
6. Predict disease risk.

## Result

The model can predict whether a patient is at risk of heart disease based on the provided medical information.
